# Vendor Risk Management Application

## Overview

The Vendor Risk Management Application is a Capstone project designed to help organizations evaluate, manage, and monitor third-party vendor risk.

Features include:
- Vendor management
- Risk assessments
- Risk scoring
- Dashboard metrics
- Reporting

## Technology Stack

- HTML
- CSS
- JavaScript
- Claude AI assisted prototyping

## Current Status

Currently in prototype and early development phase.

## Running the Project

Open the project files in a web browser or local development environment.
